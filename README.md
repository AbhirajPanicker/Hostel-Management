Hostel Management System

A web-based hostel management system that helps manage students, rooms, hostel records, and administrative tasks efficiently.

Features

- Student management
- Admin dashboard
- Room allocation
- Student registration
- User authentication
- Database integration

Technologies Used

- PHP
- MySQL
- JavaScript
- HTML
- CSS / SCSS

Requirements

- PHP 5.6 or 7.4
- MySQL
- Apache Server (XAMPP / WAMP / LAMP)

 Installation

1. Clone the repository:

```bash
git clone https://github.com/AbhirajPanicker/Hostel-Management.git
```

2. Move the project folder to:

```text
htdocs/
```

3. Start Apache and MySQL using XAMPP.

4. Create a database named:

```text
hostelmsphp
```

5. Import the `hostelmsphp.sql` file.

6. Open the project in your browser:

```text
http://localhost/Hostel-Management
```
